# GoLocal — 出海文化避雷与文案本地化助手

## 项目简介
GoLocal 是一个面向出海团队的轻量化本地化辅助网页原型。用户选择日本、美国或泰国作为目标市场，填写产品信息后，可以查看本地化中文文案建议、外语示例短句、跨文化风险提示和市场适配建议。

## 如何运行
1. 解压项目压缩包。
2. 打开 `index.html`。
3. 使用 Chrome、Edge 等现代浏览器即可运行。
4. 无需安装依赖、无需启动服务器、无需 API Key、无需联网。

## 功能
- 日本、美国、泰国三个目标市场切换
- 产品名称、卖点、目标人群、营销目的和文案风格输入
- 本地规则与模板生成营销表达建议
- 跨文化风险提示与市场适配建议
- 复制生成结果

## 技术说明
项目使用原生 HTML、CSS 和 JavaScript 实现，所有逻辑均在浏览器本地执行，不调用外部大模型 API，不上传用户输入内容，也不会产生 API 调用费用。

**重要说明：** 本项目是规则模板驱动的概念验证原型，不是真正接入大模型的 AI 系统。外语短句仅用于演示，正式商业发布前应由目标市场母语者校对，并核验当地法律法规、广告规范、食品标签及进口要求。
